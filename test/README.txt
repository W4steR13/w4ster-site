W4steR v5 — гибрид v3 + v4

Идея: минимальная чёрная база v3 + яркая типографика/акценты v4.
Фотографического hero-фона нет: фон строится HTML/CSS-текстом, линиями и цветом.
Кастомного курсора нет. На мобильном релизы показывают миниатюры без hover.

Для быстрого ребрендинга следующего релиза меняйте --pink и --acid в :root style.css, обложку и текст свежего релиза.
Логотип и обложка пока загружаются с w4ster.ru, поэтому для локального просмотра нужен интернет.


v5.1: hero переведен на viewport-responsive размеры; увеличен line-height крупных заголовков, чтобы строки не налезали друг на друга на разных разрешениях.
