# NODEWORK — файлы публичных сборок

Этот каталог зарезервирован для проверенных архивов NODEWORK.

Планируемый адрес первой сборки:
`https://w4ster.ru/nodework/downloads/NODEWORK_Alpha_0.14_windows_x64.zip`

## Порядок публикации

1. Сначала проверить новую Windows x64 Release-сборку и её лицензии.
2. Загрузить итоговый ZIP в `nodework/downloads/` ветки `release/nodework`. Не загружать сюда непроверенные сборки и исходники.
3. Сверить SHA-256 загруженного файла с локальным оригиналом.
4. Дождаться успешного workflow `.github/workflows/publish-nodework.yml`, который переносит `nodework/` в `main`.
5. Проверить прямой URL архива (HTTP 200, скачивается полный ZIP), затем обновить **встроенный** `window.NODEWORK_SITE.downloadUrl` в `nodework/index.html` (текущий сайт использует встроенную конфигурацию, не внешний `site.config.js`).
6. Повторно проверить страницу, кнопку скачивания и контрольную сумму.

**Важно:** GitHub не позволяет загрузить 60-МБ архив через веб-редактор (лимит 25 МБ); нужен обычный `git push` или другой способ доставки файла. GitHub ограничивает размер одного файла в репозитории 100 МБ. Если ZIP окажется больше, используйте GitHub Releases или отдельное файловое хранилище, а не Git LFS для GitHub Pages.

Пока ZIP не опубликован и проверен, кнопка загрузки на сайте должна оставаться неактивной.
