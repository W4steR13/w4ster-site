# NODEWORK — сайт первой публичной альфы

Отдельный статический сайт игры NODEWORK от **W4steR Games**. Оформление: бумага, дерево, листья, настоящие скриншоты игры. Сайт не запускает игру в браузере: он рекламирует скачиваемую Windows-версию.

## Быстрый запуск

Открой `index.html` локально в браузере. Для проверки без особенностей `file://` можно запустить веб-сервер:

```bash
python -m http.server 8080
```

Затем открыть http://localhost:8080/ . Сборка не нужна: HTML, CSS и JavaScript без внешних библиотек.

## Перед публикацией

1. Убедись, что есть проверенная **Windows x64 Release-сборка** игры. Здесь игры/установщика **нет**.
2. Создай GitHub Release, прикрепи ZIP сборки и скопируй прямой HTTPS-адрес файла.
3. Открой `site.config.js` и укажи `downloadUrl`. Пока адрес пуст, сайт честно показывает «Сборка готовится».
4. Там же укажи реальный `repositoryUrl`, например `https://github.com/W4steR13/nodework`, после создания репозитория.
5. Если версия изменилась, поправь `version` и сведения на странице.
6. Проверь тексты и скриншоты относительно итоговой публичной сборки; изображение долины в первом экране — **иллюстрация, не скриншот игры**, это указано на сайте.

## Новый репозиторий GitHub

Подключённый в ChatGPT GitHub-профиль: `W4steR13`. Желаемый репозиторий — `W4steR13/nodework`. Имя `w4ster/nodework` принадлежало бы другому владельцу, если только такой аккаунт/организация не предоставил доступ.

1. В GitHub создай **пустой** публичный репозиторий `nodework` в аккаунте `W4steR13` (без автоматических README или других файлов).
2. Загрузи содержимое этой папки в корень репозитория, например командой:

```bash
git init
git add .
git commit -m "Initial NODEWORK alpha website"
git branch -M main
git remote add origin https://github.com/W4steR13/nodework.git
git push -u origin main
```

3. GitHub → Settings → Pages → Deploy from a branch → main → /(root). Сайт будет доступен по адресу `https://w4ster13.github.io/nodework/` **после** включения Pages и успешной публикации.

Если позднее понадобится маршрут `w4ster.ru/projects/nodework/`, готовые относительные пути позволяют перенести те же файлы в каталог `projects/nodework/` действующего репозитория сайта `W4steR13/w4ster-site`. Текущий ZIP **не изменяет** существующий музыкальный сайт.

## Содержимое

- `index.html` — страницы/секции: мир, механики, скриншоты, дневник, загрузка.
- `styles.css` — адаптивный «бумажно-деревянный» стиль.
- `script.js` — мобильная навигация, галерея и конфиг релиза.
- `site.config.js` — версия, GitHub и настоящая ссылка на скачивание.
- `assets/` — оптимизированные WebP и PNG, включены в репозиторий, не зависят от внешних CDN.

## Проверки

- Адаптивность: 360px / 768px / десктоп.
- Галерея открывается по клику, закрывается клавишей Escape, переключение клавишами стрелок.
- Есть skip-link, атрибуты alt, поддержка `prefers-reduced-motion`.
- Фальшивая ссылка на Windows-сборку не выводится.
