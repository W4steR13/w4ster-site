# NODEWORK — публикация через release-ветку

Эта ветка используется для подготовки отдельной страницы игры NODEWORK, не затрагивая основной музыкальный сайт.

## Публикация

1. Переключиться в GitHub на ветку `release/nodework`.
2. В корень ветки загрузить целиком папку `nodework/` из подготовленного архива сайта (внутри должны быть `index.html`, `styles.css`, `script.js`, `site.config.js` и `assets/`).
3. Коммит файлов `nodework/**` запускает workflow `.github/workflows/publish-nodework.yml`.
4. Workflow переносит **только** `nodework/` в ветку `main`, не меняя корневой сайт.
5. Сайт станет доступен на `https://w4ster.ru/nodework/` при действующей публикации GitHub Pages из `main`.

Важно: ссылка на скачивание игры не должна включаться до загрузки проверенной публичной сборки. Для обновлений меняйте содержимое `nodework/` в `release/nodework`, не редактируйте сгенерированную копию в `main`.
